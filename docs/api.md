# API 参考

以下接口仅用于文档展示，不提供真实服务，目的是练习在文档中清晰地描述一个 API。

## 查询文档列表

- 请求方法：`GET`
- 请求路径：`/api/docs`
- 功能：返回文档条目列表。

### 请求示例

```bash
curl -X GET "https://example.com/api/docs?page=1&size=10"
```

### 返回示例

```json
{
  "items": [
    { "id": 1, "title": "使用指南" },
    { "id": 2, "title": "关于本项目" }
  ],
  "total": 2
}
```

## 返回字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | 整数 | 文档唯一标识 |
| `title` | 字符串 | 文档标题 |
| `total` | 整数 | 条目总数 |

## 常见状态码

| 状态码 | 含义 |
| --- | --- |
| `200` | 请求成功 |
| `404` | 资源不存在 |
| `500` | 服务器内部错误 |

## 设计说明

上面的示例刻意做到了「自解释」：用表格列出字段和状态码，用代码块给出可直接复制的请求与返回样例。我认为一份好的 API 文档，应该让读者不写代码也能大致看懂它在做什么。
